# 🌟 Premium Vedic Astrology SaaS 

A 3-tier production web application for exact astronomical planetary positions and traditional Vedic astrology charts (Kundli).

## 🏗️ Architecture
* **Frontend:** React + Vite + Tailwind CSS
* **Backend:** Python FastAPI + PySwisseph (Astrology Engine)
* **Database:** MySQL 8.0
* **Deployment:** AWS EC2 (Ubuntu 24.04), Nginx

## 🛠️ Features
* High-precision PySwisseph calculations
* Auto city-to-coordinates conversion
* Traditional SVG North Indian Kundli visualizer
* Sample Vedic Prediction Engine
